### Making my MVP and going beyond
In SEP, I am continuing to progress in the Freedom Project timeline by making my MVP and going beyond using HTML, CSS, Bootstrap, and Aframe. Recently in SEP, while I was showcasing my MVP to my peers, one of the specific pieces of feedback I recieved was to add more bootstrap components to my Nuclear Engineering Freedom Project Website. Before I began creating the MVP for my Nuclear Engineering Freedom Project website, I used a myriad of Bootstrap components when constructed my SHABR website. One of the components I believed can make a significant addition to my website was the carousel component. This carousel component would be used on my Freedom Project website to shwocase the Nuclear Engineering and Energy timeline, streching from the first nuclear reactor by Enrico Fermi in 1942 to modern small modular reactors in the 2020s. While creating the carousel, I ran into a few issues with the code, specifically with image sizing and the readability of the slide captions. To fix this, I used CSS properties such as `object-fit: cover` and Bootstrap classes such as `bg-dark bg-opacity-75` in order to make the captions easier to read. Furthermore, I also improved the overall styling and aesthetic of the website by introducing gradients, image hover effects, and better spacing to make the website look more professional. To refresh my memory of CSS animation and styling since I hadn't worked on it since last semester of SEP in my CSS animation presentation, I used [this youtube video](https://www.youtube.com/watch?v=z2LQYsZhsFw) and this [youtube tutorial](https://www.youtube.com/watch?v=SgmNxE9lWcY). These youtube videos refreshed my memory about CSS animation and styling and helped me achieve an MVP and Beyond MVP I was happy with, as seen in this [preview](../img/website.png)
